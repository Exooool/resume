# 简历编辑器

一个专注中文简历制作的在线编辑器。无需注册账号，打开浏览器即可完成简历创建、实时预览、模板切换和多格式导出。

[在线体验](https://exooool.github.io/resume/) · [功能概览](#功能概览) · [本地运行](#本地运行)

![简历编辑器首页](docs/screenshots/home.png)

## 项目亮点

- **所见即所得**：左侧控制与表单、右侧 A4 预览，修改结果即时可见。
- **自动分页**：根据内容高度自动拆分页面，适合经历较多的完整简历。
- **9 套模板**：覆盖经典、清新、紧凑、侧边栏、蓝灰、墨线、卡片、时间轴和极简风格。
- **多格式导出**：悬停「导出简历」可选择 PDF、PNG、JPG 或 JSON，方便投递、打印、分享与备份。
- **JSON 导入导出**：编辑时可导出完整简历数据，再通过 JSON 文件恢复内容。
- **主题与排版**：支持主题色、字体切换，以及姓名、职位、模块标题等各层级字号调节。
- **智能压缩间距**：一键将上下间距压缩至 75%，在保持可读性的前提下节省页面空间。
- **本地优先**：简历数据保存在浏览器 `localStorage`，无需后端服务，也不会上传个人信息。
- **响应式编辑**：桌面端三栏布局，窄屏设备可在编辑与预览之间快速切换。

## 功能概览

| 模块 | 能力 |
| --- | --- |
| 简历管理 | 新建、命名、继续编辑、删除多份简历 |
| 内容编辑 | 基本信息、教育经历、工作经历、项目经历、技术能力、自我总结 |
| 个人头像 | 本地图片上传、4:5 自动裁剪、更换和移除，无头像时不占位 |
| 动态表单 | 教育、工作和项目支持多项增删，模块内容可折叠整理 |
| 技术能力 | 支持分类模式和自由文本模式 |
| 实时预览 | A4 尺寸渲染、内容测量、自动分页、页数提示 |
| 模板系统 | 9 套内置模板，一键预览和切换 |
| 主题排版 | 主题色、字体、各层级字号滑块、智能压缩上下间距 |
| 文件导出 | PDF、PNG、JPG、JSON |
| 数据导入 | 编辑时通过 JSON 文件恢复简历内容 |
| 数据持久化 | 浏览器本地自动保存，刷新后可继续编辑 |
| 响应式布局 | 桌面三栏与移动端编辑/预览切换 |

## 使用流程

1. 进入简历列表并创建一份新简历。
2. 按模块填写个人信息、教育经历、工作经历、项目经历和技能。
3. 在实时预览中检查分页与内容密度，必要时开启「智能压缩上下间距」。
4. 打开模板选择器，比较并确定排版风格；按需调整主题色与字号。
5. 导出 PDF 用于投递，或导出 PNG/JPG 用于分享；也可导出 JSON 备份，日后在编辑器中导入恢复。

开发环境中可以点击「模拟数据」快速填充完整示例，便于测试模板和分页效果。

## 本地运行

环境要求：Node.js 20.19+ 或 22.12+，以及随 Node.js 安装的 npm。

```bash
git clone https://github.com/exooool/resume.git
cd resume
npm install
npm run dev
```

浏览器访问终端输出的本地地址，默认通常为 `http://localhost:5173`。

## 可用命令


## 项目结构

```text

├─ data/           # 默认简历数据和模板配置
├─ router/         # 页面路由
├─ utils/          # 简历转换、导入导出与本地存储工具
├─ views/          # 首页、简历列表、编辑器页面
├─ App.vue
├─ main.ts
└─ styles.scss
```

## 数据与隐私

简历数据以 JSON 形式保存在当前浏览器的 `localStorage` 中。项目不依赖账号系统或远程数据库，个人信息不会由应用主动上传。

编辑时导出的 JSON 文件包含完整简历内容与名称，可用于备份或在同一浏览器中再次导入恢复。清理站点数据、使用无痕窗口或更换设备后，未备份的本地简历不会自动同步。
